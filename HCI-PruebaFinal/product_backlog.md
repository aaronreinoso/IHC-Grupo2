# Product Backlog

| ID | Épica | Historia de Usuario (User Story) | Prioridad (1-5) | Estimación (Story Points) |
| :--- | :--- | :--- | :--- | :--- |
| **US-01** | Seguridad | Como administrador, quiero iniciar sesión en el sistema para evitar accesos no autorizados a los planes de prueba. | 5 (Alta) | 8 |
| **US-02** | Manejo de Errores | Como evaluador, quiero ver un mensaje de error visual (Toast) si el Dashboard no puede conectarse a la base de datos, para saber por qué no cargan mis métricas. | 5 (Alta) | 3 |
| **US-03** | Formularios | Como usuario, quiero que el campo de texto se ponga rojo al llegar al límite de caracteres en lugar de cortar mis palabras, para poder corregir mi redacción. | 4 (Media) | 3 |
| **US-04** | Navegación | Como usuario, quiero ver una página de "Error 404" con un botón de retorno si escribo mal una URL, para no quedarme atascado en una pantalla en blanco. | 4 (Media) | 2 |
| **US-05** | Responsividad | Como usuario en móvil, quiero tener un botón de "Cerrar Sesión" visible en el menú lateral, para poder salir del sistema de forma segura. | 4 (Media) | 3 |
| **US-06** | UI / UX | Como usuario, quiero ver esqueletos de carga (Skeletons) en el Dashboard mientras se obtienen los datos, para percibir una respuesta más rápida del sistema. | 3 (Baja) | 5 |
| **US-07** | Navegación | Como evaluador, quiero ver Breadcrumbs en la parte superior del formulario, para no perder el contexto de a qué plan pertenece la tarea que estoy creando. | 2 (Baja) | 2 |

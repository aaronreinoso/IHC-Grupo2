# Evaluación Heurística - Usability Test Dashboard 2.0

| ID | Módulo | Heurística de Nielsen | Descripción del Problema | Gravedad | Justificación Técnica / Sugerencia | Responsable Sugerido | Estado |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | `App.tsx` (Global) | Prevención de errores | Ausencia de Login/Auth. Se accede directamente a las rutas sin autenticación previa. | Crítica | Implementar un Auth Guard para proteger rutas y verificar sesión con Supabase. | Backend Developer | No Cumple |
| **2** | `App.tsx` (Navegación) | Ayuda para diagnosticar errores | Falta de página 404. Si el usuario ingresa una URL no registrada, la aplicación queda en blanco. | Moderada | Añadir `<Route path="*" element={<NotFound />} />` con botón de regreso al inicio. | Frontend Developer | No Cumple |
| **3** | `Dashboard.tsx` | Visibilidad del estado del sistema | Errores silenciosos en consola al fallar la carga de Supabase; no se notifica al usuario. | Crítica | Integrar el componente `<Toast />` global o un "Empty State" con botón de reintento. | Frontend Developer | No Cumple |
| **4** | `Dashboard.tsx` | Estética y diseño minimalista | Feedback de carga pobre. El `loading` muestra un spinner genérico que bloquea toda la pantalla. | Leve | Reemplazar el spinner central por Skeletons (barras de carga grises) en las tarjetas. | UX/UI Designer | No Cumple |
| **5** | `Dashboard.tsx` | Flexibilidad y eficiencia de uso | Las tarjetas de KPI principales (Participantes, Planes) no son cliqueables como accesos directos. | Leve | Envolver las tarjetas de métricas en componentes `<Link>` para mejorar la navegación. | Frontend Developer | No Cumple |
| **6** | `TareaForm.tsx` | Prevención de errores | Truncamiento silencioso. La función `value.slice` corta el texto ingresado sin advertir al usuario. | Moderada | Cambiar el borde del input a rojo (error state) y deshabilitar el botón "Guardar" al exceder el límite. | Frontend Developer | No Cumple |
| **7** | `Layout.tsx` | Consistencia y estándares | En la vista móvil, el menú no incluye opciones para ver el perfil del usuario activo o cerrar sesión. | Crítica | Agregar un footer en el sidebar con los datos de sesión y botón de "Cerrar Sesión". | UX/UI Designer | No Cumple |
| **8** | `PlanLayout.tsx` | Reconocimiento antes que recuerdo | Pérdida de contexto en la navegación profunda. No hay "Breadcrumbs" que indiquen en qué plan se está. | Moderada | Implementar migas de pan (Ej: Dashboard > Planes > Plan A > Tareas). | UX/UI Designer | No Cumple |
| **9** | `TareaForm.tsx` | Control y libertad del usuario | Si el usuario recarga la página por error mientras llena el formulario, pierde todo su progreso. | Moderada | Implementar guardado temporal en `localStorage` o evento `onbeforeunload`. | Frontend Developer | No Cumple |
| **10** | `App.tsx` (Rutas) | Flexibilidad y eficiencia de uso | La ruta `/planes-prueba/:planId` redirige forzosamente a `tareas`, saltándose la vista resumen. | Leve | Habilitar la ruta index de "Resumen" para dar contexto del plan antes de mostrar las tareas. | Frontend Developer | No Cumple |
